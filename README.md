# 衣账 · 服饰利润管家（PWA V1.0）

一款专门用于个人服饰买卖的离线账本，不需要账号、服务器、云同步或 Flutter。

## 功能

- 商品入库：图片、品牌、货号、商品名、分类、颜色、尺码、商品来源、供应商、采购日期、采购件数、单件成本、参考售价。
- 一个货号可多次采购：按采购批次录入，每批成本和来源分别记录。
- 销售登记：数量、实际单件成交价、日期；自动扣库存，保存当时进价，计算已实现毛利。
- 销售撤销：撤销记录并返还原库存；有销售历史的商品不能直接删除。
- 概览：库存件数、库存成本、本月销售金额、已实现毛利。
- 统计：今日、本月、全部；按品牌及商品来源统计利润。
- 本地存储：IndexedDB，拍摄/选择的照片自动压缩。
- 备份：JSON 完整导出和恢复（含图片、商品及销售）；CSV 表格导出。
- PWA：添加到 iPhone 主屏幕使用；首次在线打开后可离线使用。

## 部署到 GitHub Pages（仅用浏览器）

1. 登录 https://github.com ，点击右上角 **+ → New repository**。
2. 仓库名称填 `yizhang`，仓库可设为 **Public**（GitHub Free 的 Pages 通常要求公开仓库）。点击 **Create repository**。
3. **先将 ZIP 解压**，将其中 `index.html`、`app.js`、`style.css`、`sw.js`、`manifest.webmanifest`、`icons` 文件夹内全部图标及 `.nojekyll` 上传到仓库**根目录**，不要把整个 ZIP 直接上传。
4. 在仓库 **Settings → Pages → Build and deployment → Deploy from a branch**，Branch 选 `main`、Folder 选 `/ (root)`，点击 **Save**。
5. 等待 GitHub Pages 部署完成后，打开显示的站点地址，例如 `https://你的用户名.github.io/yizhang/`。
6. iPhone 用 **Safari** 打开该站点，点击分享图标 → **添加到主屏幕** → 添加。

> 上传到 GitHub 的只是空白 App 代码，不包含任何真实采购数据。个人实际录入的数据只在各自的设备内。仓库若公开，源代码可被访问，但并不因此公开你的本地账本。

## 重要注意事项

- 本应用是 **PWA**，不是 IPA 原生安装包。分享给朋友只需分享网址，朋友添加到主屏幕后数据各自独立。
- 首次需要联网打开，以便 Service Worker 缓存资源；加载后可以离线使用，离线时不要依赖首次访问未缓存的资源。
- 数据保存在当前设备浏览器对应的网站存储中。清除网站数据、部分系统清理、换手机等情况可能丢失数据；务必经常从右上角齿轮 **导出完整备份 JSON**，保存到“文件”App或外部安全位置。换手机时先保存备份，再在新设备上导入。
- iPhone Safari 标签页与“添加到主屏幕”版本可能使用不同的存储容器。**建议添加到主屏幕后才正式录入数据**，后续一直用主屏幕图标打开；如需迁移则用 JSON 备份。
- 所有金额保留到分，利润为**毛利润**：成交收入－对应已卖出数量的采购成本；不包含运费、手续费、税费等。
- 删除整个 App 或浏览器数据可能丢失账本；建议每周或每次大量录入后备份。
- 产品图片仅作为用户本地数据嵌入 JSON 备份，备份可能变大。

## 本地测试（可选）

如有 Python：在仓库目录运行 `python -m http.server 8000`，在浏览器访问 `http://localhost:8000/`；部署到 HTTPS 的 GitHub Pages 才能在手机上完整体验 PWA 离线缓存。

## 文件

- `index.html`：页面、弹窗、导航
- `style.css`：手机优先的界面样式
- `app.js`：IndexedDB 交易、库存、统计、备份导入导出
- `sw.js`：离线缓存 Service Worker
- `manifest.webmanifest`：安装信息
- `icons/`：图标

源码可供个人自行修改；没有引入第三方脚本或外部数据库。
